## Priority issues

1. **P1: headline clipping and delayed primary action.** At 390px, text bounds reach x=396.27 while the hero hides overflow. At desktop 1440×1000, 97.6px Syne wraps into six lines and the CTA begins at y=979. `index.astro` hero/H1/mobile rules around lines 255, 296, 488. Preserve the typeface; adjust size, grid minimums and spacing against actual glyph bounds. Suggested: Impeccable adapt/typeset.
2. **P1: unreadable small muted labels.** #71717a is about 4.12:1 against #09090b, and only 4.35:1 even against black, below 4.5:1 for normal text. Live network labels and local `.map-label`, `.map-separate > span`, `.field-note-link` use this tone. Fix the semantic muted-text token and verify actual surfaces. Suggested: Impeccable harden.
3. **P1: proof section delays proof.** The four panels describe external evidence without showing a real result or system. Place one existing verified artifact with context and provenance in the section; keep destinations as supporting links. Do not invent a run or metric. Suggested: Impeccable shape/layout.
4. **P2: inconsistent estate navigation and repeated decisions.** Catalog means Demos; live network omits Demos; Oma is absent; the diagram calls itself the whole network while showing only part. Use consistent names and a complete discoverable directory, compress duplicate routing. Suggested: Impeccable clarify/distill.
5. **P2: mobile menu and target sizing.** The menu stays open after an anchor choice and Escape. Network rectangles are about 29–36×16px; footer links 18–21px high. Close the disclosure predictably and enlarge touch areas without enlarging visual labels. These measurements are not a complete WCAG spacing-exception audit. Suggested: Impeccable harden/adapt, then polish.
